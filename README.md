# Frozen Warning-Ratio Protocol

A frozen warning-ratio protocol for cross-semester academic risk prediction, with an explicit analysis of observation-window timing. This repository contains the manuscript; the modeling tables and the broader dataset release are separate repositories.

## Protocol in brief

- **Task.** Predict end-of-term failure for each student before the term ends, once per test cohort.
- **Two sources.** A six-year institutional programming course and the Open University Learning Analytics dataset (OULAD).
- **Observation windows.** T = 2, 3, 4, 5.
- **Frozen ratio.** On the validation cohort, choose the intervention quota so that recall is at least 0.80; freeze the ratio; apply it once to the test cohort. No test labels are used to tune the threshold.
- **Why it matters.** A deployable warning system must fix the number of interventions before the term starts, because teacher time and tutoring seats are budgeted in advance.

## Data

| Repository | Role |
|---|---|
| [`frozen-warning-ratio-data`](https://github.com/lyh112358/frozen-warning-ratio-data) | Modeling tables for this study (`oulad/`, `private/`, T = 2–5) |
| [`used-datasets`](https://github.com/lyh112358/used-datasets) | Every table read by the related studies, one folder per study |

Institutional row keys are one-way hashes. The tables contain no names, student numbers, class, college, or gender. Missing scores are left missing. The OULAD keys are the public student keys of Kuzilek, Hlosta, and Zdrahal (*Scientific Data*, 2017, CC BY 4.0).
